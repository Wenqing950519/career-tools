# ① career-test — 求職傾向小測驗

**形態**：純 HTML（Next.js 靜態輸出，已存在於 `career-test/app/quiz`）
**階段**：我是誰 ／「我大三了，還不知道自己想做什麼」
**架構重量**：零後端 ✅ 已有

## 目的

用 15 題情境題，讓一個什麼都還沒有的人在 15 分鐘內拿到 2–4 個「值得看看的方向」。它是整條主線裡唯一「選擇題」形態的入口——因為這個階段的使用者對開放式問題最不友善（不知道想做什麼的人，填不出「你的興趣是什麼」）。

## 現狀與要改的地方

### 保留
- 15 題情境題與計分邏輯
- 純靜態、零登入

### 要改

1. **結果頁改造（最重要）**
   - 結果呈現 2–4 個方向假設，每個附：為什麼是它（引用他選過的題目）、還不確定什麼、一個 30 分鐘可完成的驗證行動（方法論沿用已收斂的 direction-explorer，但在前端寫死規則，不叫 AI）
   - 明確不呈現：單一職業配對、適合度百分比、人格類型標籤
2. **寫入 localStorage**：`ct_result` = { directions: [{name, signals[], unknown, action}], finished_at }
3. **下一步導引**：結果頁底部固定區塊——「知道方向之後，下一步是盤點你有什麼」→ 按鈕進 skill-gap；同時提供「複製我的測驗結果」按鈕（人讀格式的文字塊，見平台 PRD §6），給還沒上 localStorage 共享的過渡期用
4. **可截圖**：結果頁提供一張固定尺寸的「方向卡」視覺（2–4 個方向 + 一句摘要），這是階段 ① 的傳播素材

## 驗收

- 未做過測驗直接進 skill-gap，不會被擋，只是方向欄要自己填
- 做完測驗 → 點下一步 → skill-gap 的方向欄位已自動帶入
- 結果頁沒有任何「你適合當 XX」的字樣
