# Sources

Discovery sources by mode. All facts still require the source-level rule in governance.md.

## Mode A — Internships / Jobs (Taiwan)

Search these in order of yield; combine site filters with the user's direction keywords:

- 104 人力銀行 — `site:104.com.tw` + 職稱 + 實習｜工讀｜約聘
- Yourator — `site:yourator.co`（新創、數位職缺密度高，適合文組數位方向）
- CakeResume — `site:cakeresume.com`
- 1111 — `site:1111.com.tw`
- LinkedIn public listings — `site:linkedin.com/jobs` + Taiwan
- General web search: 「{方向} 實習 2026 台北」「{公司} 暑期實習 招募」

Query expansion: 實習／intern／工讀／長期實習／暑期實習；文組方向常用職稱（行銷企劃、社群、內容、營運、專案、企劃、HR、公關、商業開發）。

## Mode B — Student competitions (Taiwan)

Primary (covers most of the market):

- **BHuntr 獎金獵人** — `https://bhuntr.com/tw/competitions`, tags `大學`、`大學生`; also `site:bhuntr.com` + topic keywords

Long tail via web search (replaces per-school crawling):

- `site:edu.tw {topic} 競賽 大專`
- `site:gov.tw 大學生 {topic} 徵件`
- 「{topic} 黑客松 台灣 2026」「大專學生 {topic} 競賽 報名」

Government pools worth direct checks when topic-relevant: 教育部青年發展署（yda.gov.tw）、經濟部、數位發展部、各縣市青年局.

Keyword expansion: 競賽／比賽／徵件／提案／黑客松／Hackathon／Challenge／創新／創業; topic synonyms (e.g. AI → 人工智慧、生成式 AI、LLM).

## Verification targets (deep-verify phase)

For each user-picked item, open the canonical page and look for:

- 官方簡章／競賽辦法／徵件辦法 (often PDF/DOCX attachments) — deadlines and eligibility in attachments override page text
- Registration deadline vs. submission deadline (distinguish them explicitly)
- Eligibility: 在學／年級／組隊人數／跨校可否
- Deliverables and 評選方式

When aggregator and official data conflict, official wins; note the conflict in the card.
