# Catch Method

## Intake

Minimal viable intent = direction (what kind of work/competition) + location constraint + student status (年級／應屆／在學). A pasted resume summary supplies richer ranking signals (experiences, skills); treat each line as evidence usable in rank reasons.

Do not run any search before intent is minimally established. Do not ask more than three questions total.

## Candidate collection

- Target 12–20 raw candidates before filtering, from at least two source types (see sources.md).
- Record for each: title, organizer/company, deadline (+ source level), eligibility, URL, discovery source.
- Prefer listings published or updated within the last 60 days for jobs; for competitions, deadline governs, not publish date.

## Filtering order

1. **Expired** — deadline before today: discard, count, report the count.
2. **Ineligible** — objective rules the user cannot meet (not a student, wrong region, team size impossible): discard, list each with the rule that killed it.
3. **Hard constraints** — user's stated non-negotiables: discard, list each.
4. Preferences never discard. They reorder.

## Deduplication

Same opportunity found via multiple sources (aggregator + school repost + official) = one entry. Canonical URL = official site when found, else the most authoritative available. Keep `discovered via` as a note when relevant.

## Ranking

Order by a composition the user can audit:

1. Deadline pressure (closing soon and matched → surface early, flag the urgency)
2. Evidence match — how many of the user's own experience lines map to the requirements; cite the mapping
3. Gap size — requirements the user has not mentioned are listed as 缺什麼, phrased as things to add, never as disqualification

Tie-breaks favor verified-deadline items over unverified ones.

## Lazy deep verification

The initial list uses shallow data. After the user picks 2–3 items, open the official page (and rules PDF if linked) to confirm: deadline, eligibility, deliverables, team requirement, prize/salary range. Update the cards and upgrade their fact source level to 官方. Never deep-verify more than the user picked.
