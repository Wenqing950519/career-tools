# Example input — standalone mode

沒有注入任何 confirmed 素材，也沒有 `confirmed_source_ids`。使用者直接在對話中開始。

目標：數位行銷實習。

使用者第一句：

> 我大三，我有幫忙處理系上的活動，還有幫社團管過粉專，想找行銷實習但不知道履歷怎麼寫。

後續回答（分三輪取得）：

- 場景：系學會的迎新活動，去年九月，籌備大約六週；粉專是同一個系學會的，管了三個學期。
- 個人負責：活動是跟兩個同學一起做，他自己負責文案和報名表單，場地和預算是別人處理的；粉專是他一個人在經營，貼文自己寫自己排。
- 可數的東西：迎新報名人數「大概一百多人，我記得表單是 130 幾筆」；粉專「接手的時候兩百多人，我離開的時候快九百」；貼文頻率「大概每週兩篇」。活動後有沒有帶來社團招募成長，他說不知道。

確認回合：兩段草稿都問過「這樣寫有沒有超過事實？」，使用者都回覆沒有；其中粉專那段他主動把「大幅成長」改成實際數字。
